# Resume Builder & Application Management System

A web-based PHP and MySQL application for creating, storing, updating, and reviewing candidate resumes.

## Technologies
- PHP
- MySQL
- MySQLi
- HTML5
- CSS3
- JavaScript
- jsPDF
- html2canvas

## Features
- Resume creation and editing
- Personal, education, experience, skills, projects, certifications, internships and language details
- Dynamic form sections
- Resume preview
- Client-side PDF generation
- MySQL data storage
- Admin application listing and resume viewing

## Setup
1. Create a MySQL database and the required `resumes` table.
2. Update the database values and admin email in `config.php` with your local/server credentials.
3. Run the project on a PHP-enabled server such as XAMPP, cPanel or Apache.

> Never commit real database passwords or other secrets to a public repository.
